## 3. Detailed Architectural Notes

### 3.1 Timing of Cross-Device Relays in Fused Layers (P0-1)
In `exec_fused_tail_and_head`, concatenating `tail(L_cur)` and `head(L_next)` into a single topology list causes segment flushes on device $D$ during `tail` to observe relays belonging to `head(L_next)`. Because `executed_relays` deduplicates pointers, firing the copy before `head` computes `r.src` commits stale uninitialized bytes into the closure input buffer.
Fixing this requires restricting `run_boundary_copies` so that relays belonging to `layer_head` are eligible ONLY after the node list traversal has transitioned past `dense_tail.size()`.

### 3.2 Scratch Arena Lifetime & Single-Break Architecture
The review confirmed that non-carry scratch space in `layout_arena` is shared across layers starting from byte offset 0. Graph-level fusion cannot safely cross layer boundaries into `Head(L+1)` without causing scratch aliasing. Fusing within the layer as `[MoE(L) + Tail(L)]` delivers the true "single-break per layer" architecture.
